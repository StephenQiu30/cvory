# 在线简历制作设计


评审稿 · 2026 年 11 月 24 日。需求来源为[极简简历制作需求](../requirement/01-极简简历制作需求.md)。模板、编辑器和导出体验的比较见[调研报告](../research/05-简历制作市场调研与输入体验设计.md)。下文明确标注首版设计提案，供产品与研发评审。

## 1. 摘要

用户比较纸样，选一款进入空白简历，写入自己的经历，预览后导出。模板页用于选择纸样，编辑器用于制作，「我的简历」按岗位管理多份稿件。示例仅在挑模板时出现，编辑后的正文归用户所有。首版优先在线填写与成品导出，空白 Word 下载已移出范围。

## 2. 参与者

挑模板的访客关注版式是否适合自己的履历。撰写者可以是同一人，关注输入能否留下、导出的文件能否投递。产品负责人确认范围和样张，设计负责中文排版和交互，前端负责编辑、草稿与导出，测试负责跨浏览器和成品核对。实施人员与排期由项目另行安排。

## 3. 背景

调研中的老鱼模板详情能在桌面同时展示纸样和使用入口，同一页面在 390px 窄屏首屏只显示部分纸张。一个人能在缩略图上选中模板，不能证明他能在手机上开始写。另一项差别发生在下载时，用户在模板页就需要知道完成后能拿到什么文件。现有仓库可运行项目知识库，简历产品前端需独立建设。

## 4. 目标

| 需求 | 在产品里如何兑现 |
| --- | --- |
| FR-CV-01、NFR-CV-01 | 在首屏用同一份示例比较免费模板。每张卡片就近提供「使用模板」 |
| FR-CV-02、NFR-CV-02 | 手动填写、粘贴、修改都能从带标签的字段完成。键盘和触屏都可操作 |
| FR-CV-03、BR-CV-02 | 在线写完即可导出本人的简历。首版入口集中在在线制作和成品交付 |
| FR-CV-04、FR-CV-05 | 游客先写；账号内按岗位管理多稿，在本人的设备之间自动同步 |
| FR-CV-06、FR-CV-07 | 当前简历可以调整字段、显隐、顺序及排版，公共模板独立维护 |
| BR-CV-01 | 全程由用户决定文字和版式。页面、接口与依赖清单均排除 AI 功能 |

## 5. 使用场景

- **第一次挑模板。** 看同一份虚构履历在三种版面上的日期、段间距和字体，打开大图比较，再用选中的模板开始写。
- **手上已有文字。** 把两行项目成果粘贴进同一条经历，发现第二行写错后，就地修改并核对纸面。
- **第二天继续写。** 在原浏览器点「继续编辑」，补上一段经历，尝试另一种排版，再导出刚修改的版本。
- **只有手机。** 在 390px 宽度单栏填写，切到预览看页数，回到刚才的条目继续输入。

## 6. 价值

挑模板的人在写第一行之前就能看清纸面和交付方式。写简历的人只维护一份正文，换版式、回访和导出都能复用。最有价值的交付物是一份内容完整、能读能复制的简历文件。

## 7. 方案

**已确认的首版基线。** 三款免费模板、固定五章、按岗位管理多稿、先写后用邮箱验证码认领、本人跨设备离线合并、桌面三栏与手机切换、免费无水印中文 A4 PDF。逐项决定见[需求分析导航](../requirement/00-需求导航.md)。

### 页面与纸样

| 页面 | 默认内容与操作 | 返回、恢复和小屏 |
| --- | --- | --- |
| 模板页 | 标题「简历模板」，一行说明免费填写和 PDF 导出。每张纸样显示名称、适用内容和「使用模板」。点纸样可放大 | 关闭预览回到原卡片。检测到草稿时显示「继续编辑」及上次保存时间。从编辑器的次级菜单换款时保留原文、顺序和显隐 |
| 编辑页 | 顶栏展示文档名、保存状态和「下载 PDF」。切换模板为次要动作。宽屏从左至右排列章节导航、表单、纸面。首次进入可立即输入姓名或添加经历 | 两栏排不开时改为「填写／预览」标签。两个视图共用草稿，分别保留滚动位置。点预览中的经历可定位同一条目 |
| 空稿与错误 | 空页面保留字段标签和输入示意。完全空白时在导出位置解释「填写一项内容后即可下载」 | 输入、保存、排版失败在相应位置提示。保存不可用时只要内存正文可用，仍可导出 |

三款模板使用同一份虚构中文履历制作缩略图。**经典单栏**用左对齐姓名、较宽行距和字重划分章节。**紧凑单栏**用右对齐日期、细分隔线和较小段距容纳更多项目。**中文书简**用黑体标题和宋体正文留出呼吸空间。三款均为白底直角 A4，过长内容自然分页。设计交付时分别提供一页及两页样张。

### 我的简历与跨设备保存

游客在本机填写和导出，主动选择跨设备保存时用邮箱验证码认领。当账号已有简历时，把本机稿作为新稿加入列表。相同认领请求重试只创建一份。「我的简历」提供按岗位新建、复制、改名、切换、确认删除。复制得到独立文档，设备和账号按文档 ID 区分稿件。

### 输入合同

| 区域 | 用户填写什么 | 展示与校验 |
| --- | --- | --- |
| 基本信息 | 姓名、意向岗位、电话、邮箱、所在地 | 字段独立可选。只显示有值的联系方式，自动收起多余分隔符。导出提示不强迫用户公开电话 |
| 教育 | 学校、专业或学位、起止月份、补充说明 | 可添加多段。日期可留空或只填一端，显式「至今」与结束月份互斥 |
| 工作、项目 | 公司或项目名、岗位或角色、起止月份、多行经历 | 一次添加一条，可修改、删除。按用户设置的顺序排版，保留换行。结束早于开始时标明字段，原输入保留供修正 |
| 技能 | 自由填写多行文字 | 按原顺序展示，整段为空则收起技能标题 |

空白和全空格字段不占纸面。样例提示与默认文档名均不计为用户内容。仅当有正文且显式日期冲突已修正时可以导出。中文输入法组合期间维持输入值与光标，完成选词后更新排版。粘贴按纯文本处理，保留换行。删已有内容的条目须确认并说清将删除哪一段，取消时保留原文。

### 自定义内容与排版

五个预设章节可调整顺序和显隐。隐藏保留原数据，删除已有经历需确认。可选字段、条目顺序和排版覆盖值归当前简历。排版面板提供中文黑体／宋体、字号、行距、紧凑／标准／宽松间距和预设主题色。对齐老鱼可观察的配置维度，具体字号范围、档位数值和色板用中文纸样核验。三款模板继续作为公共预设。当前稿从次级菜单换款时保留正文、条目顺序和隐藏设置。用户改过的设置逐项保留，其余取新模板默认值。恢复默认清空本稿的全部覆盖项。见[排版需求](../requirement/12-个人简历排版设置.md)。

### 组件与视觉

桌面章节标题 17px、输入 14px、操作 13px。字段默认无边框，用浅底表达可输入区域；键盘聚焦用蓝色标记，错误补充可读文字。手机输入 16px。

沿用简序历史设计的近白画布、白纸、深色主操作和少量蓝色焦点。以 4px 网格组织间距，控件 6px 圆角，表单保留常驻标签。手机输入字号从 16px 起，主要点击区域至少 44px，页面允许缩放。键盘焦点清楚可见。中文字体优先保证字形完整，并保留后备字体。[简序历史规范](https://github.com/StephenQiu30/cvory/blob/3a0a8e91db6dbc1686157176a976239ed6a3e021/DESIGN.md) · [Vercel 交互指南](https://vercel.com/design/guidelines)

| 行为 | 产品前端组件 | 核对方式 |
| --- | --- | --- |
| 纸样放大、删除确认 | shadcn/ui Radix 系列的 Dialog、AlertDialog，给弹层可读标题 | 键盘打开，焦点进入浮层，取消或 Esc 后回到触发器。删除后移到相邻条目或添加按钮。[Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog) |
| 填写、字段错误 | FieldGroup、Field、FieldLabel 配合原生语义的 Input、Textarea。FieldError 与控件关联 | 逐字段朗读标签和错误，失败后可继续修改。[shadcn/ui Field](https://ui.shadcn.com/docs/components/radix/field) |
| 窄屏填写及预览 | Radix 系列 Tabs、TabsList、TabsTrigger、TabsContent | 方向键切页，选中项和焦点可辨。换页保留编辑位置。[shadcn/ui Tabs](https://ui.shadcn.com/docs/components/radix/tabs) |
| 保存和导出 | Button、行内状态文字、可重试的 Alert | 保存成功才报「已保存到此设备」。导出中保留按钮名称，阻止重复生成 |

### 内容、持久化与导出

| 职责 | 数据和接口约定 | 异常处理 |
| --- | --- | --- |
| 草稿与模板 | 每份简历有独立 docId；Y.Doc 保存稳定条目 ID、按序章节和经历、个人字段、模板 ID 与排版覆盖值，公共模板单独维护。持续输入映射到共享文本类型 | 隐藏与删除分开；复制创建新文档；换模板保留个人正文 |
| 本机与远端 | y-indexeddb 支持本地恢复，Yjs 更新经鉴权连接同步。服务器校验当前用户对文档的所有权，保存更新后回执。前端区分本机已保存、待同步、已同步 | 离线可写和导出。重连交换差异并自动合并；重试或乱序更新最终收敛。删除后的迟到更新不可复活稿件。邮箱验证码需过期、限频、单次使用 |
| 排版与预览 | 输入正文、模板和版本号，输出分页位置、条目坐标及 PDF 字节。优先验证 @react-pdf/renderer 的字体注册、文档布局与自动分页，由 PDF.js 预览同一份 PDF。pdf-lib 与 fontkit 作为低层备选。PDF.js 本身用于阅读渲染。长段按行续页，章节标题与首行同页 | 渲染只接纳当前版本。字体载入或排版失败允许重试。等最新版本生成后才能下载，避免导出上一稿。[pdf-lib](https://pdf-lib.js.org/) · [PDF.js](https://mozilla.github.io/pdf.js/examples/) |
| 文件与隐私 | 建议用文档名或「简历」作为文件名，去掉非法文件名字符。游客正文保存在本机，排版与导出可本地完成。用户开启同步后向本账号的文档服务发送更新，模板与字体独立分发 | 记录验证结果时使用虚构履历。日志、地址和测量事件均不携带姓名、联系方式或经历正文 |

开源样张发现默认断行可能截断连续中文。候选库必须完整保留中文长段并通过手机及离线核验。[开源选型与实测](../research/07-开源编辑同步与PDF排版选型.md)

本机数据、同步消息与渲染输入仅支持现行契约。遇到不受支持的格式时停止本次写入并给出错误。[单一现行数据契约](../requirement/13-单一现行数据契约.md)

字体体积、中文断行和手机内存占用需要先做样张验证。可替换排版库，只要预览与导出继续使用同一版文件并满足文字提取验收。

## 8. 实施与验收

| 技术验收 | 用什么数据核对 | 可观察结果 |
| --- | --- | --- |
| 正文独立于模板 | 同名公司两条经历、中文换行，依次切换三款 | 文本、id、顺序一致，纸面点击命中正确条目 |
| 保存与恢复 | 刷新、断网、两台设备分别修改后重连 | 成功保存可恢复。重连后两端收敛，远端持久化后显示已同步，其他账号无法读取 |
| 文件可信 | 三款各用中英混排一页和两页，含长公司名、跨页段落和空章节 | 六份文件均为 A4，预览与下载内容及页数一致。能提取中文，无水印、空章节、截断或整页图片 |
| 可操作 | 仅用键盘完成主流程，使用真机中文输入法和 390px 视口复核 | 标签清楚、焦点可见、按钮可达，切回填写仍可修改原段 |
