# 在线简历制作执行计划


唯一来源 PRD 为[在线简历制作 PRD](../prd/01-在线简历制作PRD.md)。目标是在产品前端交付从选模板、在线填写到成品导出的完整流程。任务调度与实施状态集中在[项目 BACKLOG](https://github.com/StephenQiu30/cvory/blob/main/BACKLOG.md)。

## 前置与工程责任

仓库已有独立的知识库服务。下列 frontend 路径是产品实施时建议创建的责任边界，具体框架版本、浏览器支持版本及字体授权在 T-CV-01 记录。样例统一用虚构中文履历，准备一页与两页两组，覆盖长公司名、同名条目、缺失日期、中英混排、中文标点和跨页多行文字。

| 交付位置（拟） | 责任 |
| --- | --- |
| frontend/ 页面入口、components/ui/ | 模板页和编辑页的导航、shadcn/ui Radix 配置及交互组件 |
| frontend/ 下的 resume/、templates/ | 正文模型、草稿版本、三份模板定义、示例与用户数据隔离 |
| frontend/ 下的 editor/、storage/ | 字段与条目操作、视图和焦点、本地持久化和冲突恢复 |
| frontend/ 下的 document/、公开字体资源 | 字体许可、断行分页、同一份 PDF 的预览和下载 |
| frontend/ 下的 tests/、fixtures/ | 虚构样例、浏览器流程、PDF 内容检查和可复核样张 |
| 后端身份与同步服务（拟） | 邮箱验证码、会话、所有权校验、按文档保存更新、持久化回执及删除管理。模板库只读 |

## 验证与证据

- **浏览器。** 在桌面 Chromium 用键盘完成全流程，在 390px 视口验证布局，再用真实手机中文输入法复测组合输入与文件获取。记录浏览器、系统版本、视口、复现步骤和实际结果。
- **草稿。** 保存成功后刷新比较字段与顺序。阻断写入后继续键入并导出，恢复存储后重试。在两个标签用相同初始版本修改，分别核对已持久化和未保存的内容。
- **文件。** 对每份成品用 PDF 阅读器或 pdfinfo 查纸型和页数，用 pdftotext 或等价工具核对中文与换行。对照最终预览，人工检查断页、长行、页边距和空白尾页。证据注明样例、模板与代码版本。
- **产品。** 分别记录独立完成和选模板任务的分母、成功数、耗时及干预点。用户可用性测试与自动化结果不可互相代填。发布前由产品核对 PRD 所列门槛。

## 现行契约与失败处理

首版从空产品开始，只实施现行契约。评审本机、同步和渲染入口，移除历史格式适配、双读写及转换任务。使用不受支持的输入验证操作终止且现行稿未被覆盖，记录 CASE-CV-11。

PDF 路线未通过 T-CV-02 时，继续用同一组样例评估替代实现，暂缓依赖它的集成。发布候选出现丢稿或导出错误时撤回候选构建，保留本地草稿；首次发布可停用产品入口，重新发布前用当前数据契约核验修复构建。回退后重新走续写与导出两条路径。
