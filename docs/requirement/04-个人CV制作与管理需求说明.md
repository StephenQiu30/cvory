# 个人 CV 制作、管理与展示需求

最初诉求见[原始需求 01](01-个人简历网站原始需求.md)，本说明归并后续业务补充。对应[产品设计 02](../design/02-CV制作管理与展示设计.md)。

## 1. 产品目标

建设可供多人注册使用的简历制作和管理工具，同时让每位用户展示自己选定的简历信息。保持简单，只需要少量模板，不做完整求职平台或通用个人主页系统。

## 2. 使用者

- 用户／所有者：注册并管理自己的账户，整理经历、维护不同用途的 CV、调整模板、导入导出文件，并决定对外展示什么；不同用户的私有数据隔离。
- 访客：无需注册，通过网址直接阅读对应用户已公开的个人信息和经历，不能修改或查看私有简历。

## 3. 核心能力

| 能力 | 需要得到的结果 |
| --- | --- |
| 用户账户 | 多人可注册和登录；每位用户维护自己的账户资料，安全访问各自私有内容并退出账户 |
| CV 制作与保存 | 填写基本信息、教育、工作、项目、技能、简介及补充经历；正文支持富文本和 Markdown 表达，可持续编辑保存 |
| 版本管理 | 管理不同用途的 CV，能够命名、复制、继续修改和删除，避免版本互相覆盖 |
| 模板调整与管理 | 使用少量模板，调整字体、字号、行距、间距等排版，保留个人样式，不需要重新填写内容 |
| 简历导入 | 导入已有简历，校对后继续编辑，减少重新录入；具体格式和保真范围由设计评估 |
| 数据导出 | 备份可编辑数据，或导出可复用的 Markdown；说明两者保留能力的差别 |
| PDF 导出 | 输出可阅读、投递和打印的 PDF，内容与所选版本和样式一致 |
| 个人简历展示 | 从已有 CV 选择公开信息，在电脑和手机网页中阅读，并能更新或撤回展示 |

## 4. 完整使用关系

新建或导入 → 编辑与校对 → 按用途管理版本、调整模板 → 保存 → 导出文件，或选择公开内容展示。

CV 是内容来源，模板负责排版；导出得到文件，公开展示得到网页，不再维护另一套人物资料。富文本用于编辑，Markdown 用于部分内容表达和交换；不要求整份 CV 都写成 Markdown。

## 5. 范围边界

制作流程友好、导入导出可理解、内容不丢失，是核心体验。用户之间的私有数据，以及私有简历与公开内容应清楚区分。邮箱验证、账户恢复、删除与管理方式由设计提出方案并等待确认。

不包含 AI 生成/翻译、招聘投递、模拟面试、会员支付、社区、多人协作、模板市场、博客或通用页面设计器。修订历史、OCR、访客 PDF 等未明确要求的能力不默认加入。
