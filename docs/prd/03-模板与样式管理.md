# 模板与样式管理

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-03。目标验收覆盖本能力全部范围，实施与验证状态见 BACKLOG；列出验收不表示已经通过。

## 1. 用户结果与边界

作为所有者，我希望切换少量模板、调整排版并保存个人样式，避免重复填写内容。

范围：内置模板、有效样式参数和命名预设；不做模板市场、可视化画布或代码模板编辑器。

## 2. 验收条件

- **AC-CV-17**：在全部选定内置模板间切换，内容、列表和显示规则完整，允许页数变化。
- **AC-CV-18**：可调整已确认参数，预览立即反映；应用才保存，取消还原，恢复默认不删正文。
- **AC-CV-19**：可命名、改名、应用、删除个人样式预设；内置模板不可删除。
- **AC-CV-20**：修改或删除预设不追改已有 CV；预览使用该 CV 保存的有效配置，PDF 复用该配置由 PDF 能力验收。

- **AC-CV-50 兼容模板**：三个模板读取相同内容模型；备份遇到未知模板时保留正文并提示兼容处理，不清空经历或隐藏状态。
- **AC-CV-51 预览边界**：明确编辑预览与精确 PDF 分页的关系；缩放、手机切换预览不改变保存的字体、间距或内容，字体缺失不伪装成原版式。
