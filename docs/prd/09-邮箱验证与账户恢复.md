# 邮箱验证与账户恢复

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-09；负责人要求实施邮箱验证与账户恢复，实施和验证状态见 BACKLOG。

## 1. 用户结果与边界

作为用户，我希望能证明邮箱由我控制，并在忘记密码或凭据泄露后安全恢复账户，而不丢失自己的简历。未验证用户可使用私有工作区，但须验证邮箱后才能新建或更新公开发布；历史公开快照不自动撤回。真实公网可用性依赖发信、域名和部署环境。

## 2. 建议验收条件

- **AC-USER-09 验证**：验证链接建议 24 小时有效，须以目标账户登录并明确确认。其他账户、过期和重放不能验证；重新发送使旧链接失效；GET 或邮件扫描不会直接验证。未验证用户的发布或更新被拒，现有公开快照和私有资料保留。
- **AC-USER-10 恢复**：已存在、不存在或未验证邮箱获得一致公开反馈；仅已验证且可用的账户接收建议有效期 30 分钟的重置链接；只接受有效、未使用且目的匹配的凭据，修改失败保留原密码。
- **AC-USER-11 安全重置**：成功后旧会话、其他有效重置凭据失效，用户手动重新登录；并发提交最多成功一次，不泄露重置凭据。
- **AC-USER-12 密码变更**：已登录用户核验当前密码后可更改密码；建议新密码 15–128 字符并检查泄露密码，旧的 10–14 字符密码保持可登录；成功后撤销其他会话并轮换当前会话。
- **AC-USER-13 邮件可靠性**：重发、邮箱/IP/全局配额和投递失败按设计反馈；发送方接收不等于收件箱送达，日志、前端、错误和测试证据不包含密码或有效令牌。未验证且无法登录的账户不自动找回或移交，支持方式待确认。

## 3. 验证场景

| 场景 | 动作及结果 | 对应 AC |
| --- | --- | --- |
| 验证 | 使用独立受控邮箱测试成功、过期、重放、错误账户、邮件安全扫描、重发、发送失败及未验证发布 | 09、13 |
| 恢复与枚举 | 对存在/不存在邮箱执行相同请求；测试错误/过期/重复及并发令牌，成功后旧会话失效 | 10、11、13 |
| 密码更新 | 验证旧密码/近期认证，测试新旧规则、旧会话和失败保留 | 12 |

## 4. 待确认

方案中的验证时点、有效期及限流为具体建议；发信供应商与域名、阈值、泄露密码数据来源、争议账户和不可登录用户的支持路径、隐私保留期仍需确认。完成确认并更新设计后再执行。
