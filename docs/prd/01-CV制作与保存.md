# CV制作与保存

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-01，验收建议；原始目标已确认，具体交互尚未逐项确认。

## 1. 用户结果与边界

作为所有者，我希望新建、填写并可靠保存 CV，重新打开后仍可继续编辑。结构化字段与富文本共同组成一份 CV；空状态可进入导入能力，但本文件不定义文件解析。

范围：基本信息、重复经历、模块顺序/隐藏、头像、富文本和受限 Markdown；不建设完整文档编辑器或跨会话修订历史。

## 2. 验收条件

- **AC-CV-01**：空列表直接提供新建与导入；不先要求完成模板收藏、付费或全部资料。
- **AC-CV-02**：新建生成独立 CV，可跳过可选模块；占位示例不能混入导出。
- **AC-CV-05**：可增删和排序重复经历、编辑日期、隐藏再恢复模块与可选字段；隐藏不清空内容，非法日期有提示。
- **AC-CV-06**：保存成功后重开，字段、正文、排序、可见性、头像、模板及有效样式保持一致。
- **AC-CV-07**：保存中、成功、失败可区分；失败保留输入并可重试，离开未保存内容有提醒。
- **AC-CV-08**：中文组合输入不被转换打断；旧请求或多标签冲突不静默覆盖新内容，提示后仍可保留本地修改。
- **AC-CV-09**：工具栏与 Markdown 支持段落、强调、列表、链接及行内代码；可取消格式，控制列表层级。
- **AC-CV-10**：保存重开与预览对受支持内容表达相同语义，不显示多余 Markdown 标记；文件与公开输出的相同语义由对应能力验收。
- **AC-CV-11**：不支持粘贴格式有说明并保留可读文字；恶意链接、脚本和网页样式不被执行或带入。
- **AC-CV-12**：键盘能操作基本格式、撤销/重做与链接编辑，工具有可访问名称；当前编辑撤销不影响其他 CV。

## 3. 验证场景

| 场景 | 条件与角色 | 动作 → 可观察结果 | 对应 AC |
| --- | --- | --- | --- |
| TC-CV-01 开始制作 | 所有者，空列表 | 新建、跳过可选项、保存、返回 → 有可识别 CV，示例不当成真实内容 | 01、02 |
| TC-CV-03 内容重开 | 含多条经历、头像与隐藏字段 | 编辑、排序、隐藏恢复、保存、重开 → 内容/样式保留；非法日期有提示 | 05、06 |
| TC-CV-04 故障与冲突 | 可断网、延迟响应和打开双标签 | 中文组合输入、保存断网、重试、旧标签再保存 → 输入不丢，无假成功或静默覆盖 | 07、08 |
| TC-CV-05 语义一致 | 所有受支持富文本样例 | 工具栏/Markdown 编辑、重开和预览 → 强调、段落、列表、链接语义一致 | 09、10 |
| TC-CV-06 格式边界 | 含不支持 HTML、危险链接的合成粘贴 | 粘贴、取消格式、键盘撤销/链接编辑 → 提示且保留文字，不执行危险内容 | 11、12 |
