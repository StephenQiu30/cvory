# 个人简历展示

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-07。目标验收覆盖本能力全部范围，实施与验证状态见 BACKLOG；列出验收不表示已经通过。

## 1. 用户结果与边界

作为所有者，我希望选择 CV 的公开内容并在个人首页展示；作为访客，我希望无需登录即可阅读。

范围：站主首页、GitHub 精选项目、公开选择、预览、发布、切换、撤回与响应式阅读；不另建人物资料、博客或通用主页设计器。

## 2. 验收条件

- **AC-CV-33**：从已保存 CV 选择公开字段并预览，不重新维护人物资料；能够识别来源和未发布修改。
- **AC-CV-34**：保存草稿不改变公开页；发布成功整体替换，失败保留旧公开结果；切换来源不改变网址。
- **AC-CV-35**：未选择公开的字段、私有版本名、草稿和其他 CV 不在页面源码、初始数据、匿名接口或资源里出现。
- **AC-CV-36**：撤回后本站页面、数据与相关公开资源不再返回简历，缓存同步处理；不承诺召回访客已下载副本。
- **AC-CV-37**：访客无需登录即可阅读当前公开结果；未发布/撤回显示清楚空状态，无管理工具栏。
- **AC-CV-38**：在电脑与手机阅读时自然重排，长链接不撑出屏幕；内容是网页文字，不是不可读的 A4 图片。
- **AC-CV-39**：键盘可访问主要导航、表单、对话框和链接，焦点清楚，状态不只靠颜色；放大后关键操作仍可用。
- **AC-CV-40**：未获所有者身份或不在受控本地边界的请求不能读取私有 CV、导入原件、备份和私有 PDF，也不能进行管理写操作。
- **AC-CV-41**：active 且具有已核验 GitHub 身份的新账户可明确发布，邮箱不公开不阻塞；仍使用邮箱凭据的未绑定存量账户沿用其验证门槛，存量已发布快照不因身份迁移自动撤回。账户等待注销期间访客不能读取快照，取消注销后恢复原快照，未经明确发布的草稿仍不公开。

- **AC-CV-60 并发更新**：发布与撤回使用版本条件约束；过期候选或旧更新不能覆盖更新后的结果，也不能在撤回后未经新确认重新发布。
- **AC-CV-61 来源生命周期**：服务端阻止直接删除当前公开来源，提示切换或撤回；导入、历史恢复、样式修改和 BOSS 投递不自动改变公开快照。

- **AC-HOME-01 站主首页**：项目 `/` 展示部署指定站主已发布的简介、技能、经历、项目/教育与已选联系方式，可按目录快速查阅；手机自然重排。登录用户和匿名访客读取相同公开内容，管理入口进入独立工作区；未发布时为空状态。不能自动将首个登录者设为站主。
- **AC-HOME-02 GitHub 项目公开**：只有用户选定且明确发布的公开仓库元数据与人工贡献进入首页；刷新 GitHub 不覆盖人工文案或自动更新网页。个人稳定地址与首页读取相同快照；撤回/取消项目公开清理相应内容和缓存，私库/未选项目不泄露。

## 3. 验证场景

| 场景 | 条件与角色 | 动作 → 可观察结果 | 对应 AC |
| --- | --- | --- | --- |
| TC-CV-17 发布与更新 | 有公开结果，来源 CV 有新草稿 | 预览、保存、失败发布、成功发布、切换来源 → 仅明确成功发布更新，网址不变 | 33、34 |
| TC-CV-18 隐私与撤回 | 私有字段使用可检索合成哨兵值 | 匿名检查 HTML/初始数据/API/资源，撤回后重读 → 无私有值，旧本站公开入口停止返回 | 35、36 |
| TC-CV-19 访客阅读 | 匿名，宽屏与窄屏 | 未发布/发布后访问、缩放、打开项目链接 → 空状态正确，网页自然重排，无管理栏 | 37、38 |
| TC-CV-20 权限与键盘 | 无身份、非所有者及所有者 | 请求私有数据/写入，再键盘操作管理区 → 前者被拒；后者焦点、标签、状态清楚 | 39、40 |
| TC-CV-21 账户状态 | GitHub-only 无公开邮箱账户、存量未验证账户、等待注销账户 | 尝试新发布和匿名访问、取消注销 → 服务端按状态拒绝或恢复旧快照，不泄露草稿 | 41 |
| TC-CV-34 发布并发与来源 | 两标签、过期候选、当前来源 | 同时发布／撤回，绕过界面直接删来源，恢复／投递新版本 → 旧请求不复活公开，删除受保护，无隐式发布 | 60、61 |

补充：匿名与另一账户访问首页和稳定个人页，核对站主绑定、精选项目、响应式/目录和未发布状态；GitHub 同步失败、仓库改名/转私有后刷新及撤回分别检查（AC-HOME-01、02）。
