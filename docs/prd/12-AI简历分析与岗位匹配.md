# AI 简历分析与岗位匹配

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-12。首期支持火山引擎、DeepSeek 和 OpenAI 官方预设，每位用户自行填写 API Key 和模型。分析输入及报告正文私有保存 7 天、仅本人可读；CVory 不设置调用次数、token 或金额上限。服务商价格、上下文和数据处理政策仍需部署者核对；实现与验收状态见 BACKLOG。

## 1. 用户结果与边界

用户选择已保存版本，获得有原文依据的简历诊断、与岗位对照、段落改进和招呼草稿；审阅并采纳后才修改私有草稿。不扩为通用聊天，不自动发布、发送或改写固定投递材料。

## 2. 验收条件

- **AC-AI-01 输入透明**：调用前展示固定 CV/etag、岗位、模型、发送字段、7 天留存期及供应商可能收费；明确说明 CVory 不设置使用或金额上限。默认排除电话/邮箱/照片等非必要资料。未配置或未由用户明确发起时不擅自调用；取消或连接中断后不自动重放。
- **AC-AI-02 可解释结果**：报告标明满足/缺失/未知及来源字段/原文；不编造经历、数字、技能或录用概率。硬条件筛选不能被 AI 放宽；输出结构不合法可恢复地失败，不作为有效建议应用。
- **AC-AI-03 审阅与采纳**：逐项预览差异、采纳或拒绝；来源 etag、本地修订号或目标字段原文已变化则重新核对；分析后未保存的新输入也不能被旧建议覆盖。仅修改目标私有草稿，其余字段/经历、公开快照和已启动任务保持各自固定输入。
- **AC-AI-04 用量与恢复**：加密保存已发送输入快照，记录模型、提示版本、状态和可获得的用量；明确区分成功、失败、处理中和结果未知。超时/取消/断流不自动重复付费调用，遗留在途记录按宽限期转为未知。CVory 不设置请求、token 或金额上限。未配置或失败仍可编辑、导入导出及硬条件筛选。
- **AC-AI-05 隐私与权限**：输入与报告正文仅本人可读并使用 `AI_ENCRYPTION_KEY` 加密保存 7 天，定期自动清理；用量、状态与版本等不含正文的索引元数据按 owner 隔离并同期清理。密钥不回传浏览器或插件，不写入日志或公开页面；JD/仓库/文件里的指令不能触发工具、发送或发布。部署者须单独备份且保持加密密钥稳定。

- **AC-AI-06 官方预设**：三家预设分别显示配置/可用状态与用户配置的模型，保持所选服务商及配置版本；不访问第三方转发域名，未配置或失败不暗中切换服务商。分别核对鉴权、超时/取消、结构输出和用量字段差异，不把兼容协议视为行为完全一致；首期不启用流式调用。

- **AC-AI-07 自部署配置**：每位用户可在本人私有设置填写/替换/删除三家密钥及模型，密钥加密保存且不明文回显；空白不清空、写入失败保留原配置，访客/插件/未授权用户不得读写。连接测试与真实分析分开；测试前说明固定短提示可能产生费用，不发送私有简历或使用中心共享 Key。

## 3. 验证场景

使用合成简历和岗位，覆盖正常报告、缺失事实、无依据数值、伪造结构/URL、注入指令、服务端内容已变/仅本地未保存内容已变、部分采纳、拒绝、超时/限额/重复请求、取消及跨账户访问。比较采纳前后目标字段、公开页和投递材料，故障下验证基础工作仍可继续。

三家各有模拟适配验收与独立真实服务验收；未配置/未实测的预设不标记已经可用。模拟 provider 用于稳定故障验收；真实服务的质量、数据处理、用量和费用需在部署者明确选择后独立验证，不以模拟通过替代。真实服务验证须避免泄露真实简历，并由用户承担实际供应商费用。
