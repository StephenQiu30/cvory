# PDF导出

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-06，验收建议；原始目标已确认，具体交互尚未逐项确认。

## 1. 用户结果与边界

作为所有者，我希望下载与当前已保存版本一致、可离线阅读和投递的 PDF。

范围：A4 单页/多页、文本与链接、字体/头像和失败重试；不建设导出中心或高级印刷系统。

## 2. 验收条件

- **AC-CV-29**：导出前明确保存结果并固定内容和样式；导出中继续编辑不会混入该次文件，不能悄然导出旧版本。
- **AC-CV-30**：A4 一页/多页、中文/英文、粗体、列表、头像及长链接正确，无裁切、覆盖、孤立标题或意外空白页。
- **AC-CV-31**：正文可选、可搜、可复制，链接可访问；离线打开可读，不含隐藏字段、UI、水印及默认日期/网址页眉。
- **AC-CV-32**：生成/下载失败有明确反馈和重试，保留编辑内容；输出文件名能识别用途版本，不虚报成功。

## 3. 验证场景

| 场景 | 条件与角色 | 动作 → 可观察结果 | 对应 AC |
| --- | --- | --- | --- |
| TC-CV-15 PDF 输入一致 | 可延迟生成的已保存 CV | 开始导出后继续编辑 → 文件只来自固定输入；另测保存失败时不导出旧内容 | 29、32 |
| TC-CV-16 PDF 文件质量 | 单页/多页中文英文混排与长经历 | 实际生成、离线打开、搜索复制、点击链接 → 无裁切/空白/水印，字体、头像、链接正常 | 30、31 |
