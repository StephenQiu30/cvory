# CV版本管理

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-02，验收建议；原始目标已确认，具体交互尚未逐项确认。

## 1. 用户结果与边界

作为所有者，我希望命名、复制和删除独立用途版本，以便针对不同岗位调整简历而不影响原件。

范围：版本列表、改名、复制、删除及当前公开来源的删除约束；不做分支树、差异合并或自动翻译。

## 2. 验收条件

- **AC-CV-03**：列表能区分名称、最后保存时间、模板和公开来源；同名不覆盖。
- **AC-CV-04**：改名、打开、取消删除作用于当前对象，返回列表仍能找到已保存 CV。
- **AC-CV-13**：复制保留内容、富文本、顺序、隐藏状态、模板及有效参数，并产生可辨识新对象。
- **AC-CV-14**：原件与副本互相修改都不影响对方；重复确认不会意外多建同一副本。
- **AC-CV-15**：删除前显示对象和影响，可取消；删除任意普通 CV 不影响其他版本。
- **AC-CV-16**：删除当前公开来源前说明限制，先切换或撤回；不能连带静默清空公开网站。

## 3. 验证场景

| 场景 | 条件与角色 | 动作 → 可观察结果 | 对应 AC |
| --- | --- | --- | --- |
| TC-CV-02 列表与改名 | 两份同名 CV | 改名一份、打开另一份、取消删除 → 各自身份和保存时间清楚，原件仍在 | 03、04 |
| TC-CV-07 独立副本 | 已保存 CV | 复制、重复确认、双方分别改内容和样式 → 仅一个新副本，互不追改 | 13、14 |
| TC-CV-08 删除边界 | 普通 CV 与当前公开来源 | 取消/确认普通删除，再删公开来源 → 普通删除隔离；公开来源要求先切换或撤回 | 15、16 |
