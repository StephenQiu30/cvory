# CV版本管理

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-02。目标验收覆盖本能力全部范围，实施与验证状态见 BACKLOG；列出验收不表示已经通过。

## 1. 用户结果与边界

作为所有者，我希望命名、复制和删除独立用途版本，以便针对不同岗位调整简历而不影响原件。

范围：版本列表、改名、复制、删除、历史快照查看及恢复，以及当前公开来源的删除约束；不做分支树、差异合并或自动翻译。

## 2. 验收条件

- **AC-CV-03**：列表能区分名称、最后保存时间、模板和公开来源；同名不覆盖。
- **AC-CV-04**：改名、打开、取消删除作用于当前对象，返回列表仍能找到已保存 CV。
- **AC-CV-13**：复制保留内容、富文本、顺序、隐藏状态、模板及有效参数，并产生可辨识新对象。
- **AC-CV-14**：原件与副本互相修改都不影响对方；重复确认不会意外多建同一副本。
- **AC-CV-15**：删除前显示对象和影响，可取消；删除任意普通 CV 不影响其他版本。
- **AC-CV-16**：删除当前公开来源前说明限制，先切换或撤回；不能连带静默清空公开网站。

- **AC-CV-47 历史**：已成功保存内容有可辨识、不可变的历史快照，能查看来源、时间和内容；无变更保存不膨胀历史；编辑撤销不冒充服务端历史。
- **AC-CV-48 恢复副本**：恢复选定快照生成新的私有 CV，内容、照片、显隐和样式完整，重复确认不多建；不覆盖当前 CV、不恢复公开或投递授权。
- **AC-CV-49 生命周期**：展示实际保留范围；删除 CV／注销后按设计清理关联历史；其他账户不能列举、预览、恢复或下载。

## 3. 验证场景

| 场景 | 条件与角色 | 动作 → 可观察结果 | 对应 AC |
| --- | --- | --- | --- |
| TC-CV-02 列表与改名 | 两份同名 CV | 改名一份、打开另一份、取消删除 → 各自身份和保存时间清楚，原件仍在 | 03、04 |
| TC-CV-07 独立副本 | 已保存 CV | 复制、重复确认、双方分别改内容和样式 → 仅一个新副本，互不追改 | 13、14 |
| TC-CV-08 删除边界 | 普通 CV 与当前公开来源 | 取消/确认普通删除，再删公开来源 → 普通删除隔离；公开来源要求先切换或撤回 | 15、16 |
| TC-CV-26 历史恢复 | 多次保存、隐藏字段、头像及样式 | 查看旧快照、重复恢复、修改副本 → 快照不变，只建一份副本，原 CV／公开／任务不变 | 47、48 |
| TC-CV-27 历史边界 | 另一个账户、已删除 CV | 猜测快照、恢复、执行合成清理 → 拒绝越权，保留与清理符合声明 | 49 |
