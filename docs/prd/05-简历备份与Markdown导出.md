# 简历备份与Markdown导出

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-05。目标验收覆盖本能力全部范围，实施与验证状态见 BACKLOG；列出验收不表示已经通过。

## 1. 用户结果与边界

作为所有者，我希望导出能恢复的数据和可复用的 Markdown，便于备份或转移。

范围：JSON 备份恢复与 Markdown 语义交换；不承诺 Markdown 保留精确排版，不包含 PDF 生成。

## 2. 验收条件

- **AC-CV-25**：导出入口解释 JSON 与 Markdown 用途，不宣称 Markdown 保留精确模板与分页。
- **AC-CV-26**：JSON 重新导入能够恢复所声明版本支持的内容、样式、可见性与资源；不含认证或自动公开状态。
- **AC-CV-27**：Markdown 重新导入保留支持的正文语义，允许写法规范化；损失或不支持范围明确。
- **AC-CV-28**：导出失败可重试，下载不新建 CV、不清空编辑位置，不把临时私有资源链接冒充完整备份。

- **AC-CV-55 固定数据**：下载明确使用哪个已保存版本；未保存修改不得静默混入或丢弃。JSON 是单份 CV 备份，不默认包含历史、平台会话、任务凭据和发送授权。
- **AC-CV-56 独立恢复**：关闭原站资源访问后导入 JSON，照片与全部声明字段可恢复并继续编辑；PDF 或模型服务不可用时 JSON／Markdown 仍可下载。

## 3. 验证场景

| 场景 | 条件与角色 | 动作 → 可观察结果 | 对应 AC |
| --- | --- | --- | --- |
| TC-CV-13 备份重建 | 包含头像、隐藏内容和样式的 CV | JSON 导出后导入新 CV → 声明范围完整恢复，认证和公开状态不随包恢复 | 25、26 |
| TC-CV-14 Markdown 与下载故障 | 受支持语法、可模拟传输失败 | 导出/重导 Markdown、失败重试 → 支持语义保留，限制明确，编辑位置和 CV 数量不变 | 27、28 |
| TC-CV-31 备份独立性 | 固定版本、照片、不可访问原站、PDF 故障 | 下载并转移文件、导入、改写保存 → 资源及内容完整，无授权恢复；JSON／Markdown 不依赖 PDF／AI | 55、56 |
