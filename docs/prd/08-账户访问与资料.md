# 账户访问与资料

唯一来源 design：[设计 02](../design/02-CV制作管理与展示设计.md)。PRD-CV-08。个人工具、GitHub 登录与账户隔离为已确认方向；公网安全与恢复属于目标验收，阈值按设计及部署确定；实际状态见 BACKLOG。

## 1. 用户结果与边界

作为个人用户，我可以进入和退出自己的工作区，维护账户显示名与头像，并且只有我能读取和管理我的私有简历和样式。访客无需账户即可阅读被公开的内容。账户资料与简历人物资料分开；个人展示的发布范围由 PRD 07 验收。

PRD 09 仅维护存量邮箱兼容，GitHub-only 身份恢复由 GitHub 提供；注销由 PRD 10 处理；此文不假定相关功能已经实现。主题偏好是本地设置，不承诺跨设备同步。

## 2. 功能与验收条件

- **AC-USER-01 GitHub 登录**：用户通过 GitHub 登录创建或进入本站账户，不另设密码；state/PKCE/回调/授权码在服务端核验。取消、失效、重复回调或提供商失败不改变归属、不丢编辑输入；无公开邮箱仍可正常使用。
- **AC-USER-02 会话**：会话有效时刷新可继续访问；登出使当前会话失效，过期或无效会话不能读写私有资源；不会影响其他账户的会话。
- **AC-USER-03 资料**：用户可查看并修改自己的显示名和账户头像；空名称、无效图片和失败请求不覆盖已保存资料；账户头像与每份简历照片互不更改。
- **AC-USER-04 所有权**：账户 A 不能通过猜测标识、列表、修改、删除、上传、预设、候选或私有导出读取/改变 B 的内容；未登录请求被拒；公开内容仅由所有者确认发布。
- **AC-USER-05 输入保全**：编辑会话过期、认证或保存失败时保留本地草稿；重新登录后由用户主动重试。不同账户登录不能接收或保存上一账户的草稿。
- **AC-USER-06 反馈与键盘**：桌面和手机可使用弹窗、表单、关闭及恢复焦点；字段关联标签、错误文字与处理状态，不能仅以颜色区分。
- **AC-USER-07 公网安全**：公网开放前完成 TLS／Cookie／CSRF、可信代理和多维限流、错误枚举、会话过期与清理、日志脱敏、跨账户缓存及并发等检查；部署目标和阈值由设计方案确认后单独验收。现有本地能力不等于通过公网验收。
- **AC-USER-08 数据延续**：存量 CV、样式与公开结果在迁移及重启后保持归属与内容；`legacy` 不自动分配、已有邮箱不自动认定验证；冲突或失败保留数据。

- **AC-USER-18 跨能力授权**：历史快照、本机恢复、打印上下文、投递任务和本地设备绑定同样按 owner 隔离，账号切换不自动接续上一账户的编辑或任务。

- **AC-GH-01 身份延续**：用 GitHub 数字 ID 识别身份，login 改名仍回到原 owner；存量绑定须同时证明旧账户和 GitHub 身份，同邮箱不自动合并，冲突不移交数据，legacy 不自动认领。
- **AC-GH-02 公开项目素材**：可分页读取和选择本人公开仓库，预览来源、语言/简介/链接与同步时间并补充个人贡献；不请求私库或写权限，不凭热度编造成果。刷新失败保留旧数据并提示过期，人工文案不被同步覆盖；纳入 CV 和发布都需明确确认。
- **AC-GH-03 凭据隔离**：GitHub secret/token 不进入客户端、插件、日志和匿名页面；本站会话与 GitHub 授权分离，设备撤销与注销生效。GitHub-only 不展示本地密码恢复；已绑定账户不存在强制本地密码门槛。

## 3. 验证场景

| 场景 | 动作及结果 | 对应 AC |
| --- | --- | --- |
| 注册与会话 | 两个 GitHub 合成身份登录、取消授权、重复回调、刷新、登出与过期；单个会话失效不撤销另一账户 | 01、02 |
| 跨账户矩阵 | A 创建 CV、照片、预设、预览、PDF；B 和匿名分别尝试读写、列举与下载，全部不得取得未授权数据 | 04、07 |
| 草稿恢复 | 模拟保存前会话过期，在同账户和不同账户分别重新登录；原草稿保留且跨账户不能保存 | 05 |
| 资料与可访问性 | 修改账户资料后重开；无效图片/失败回滚；桌面和手机键盘操作弹窗 | 03、06 |
| 存量迁移 | 隔离 MySQL 复制数据，执行迁移、重复执行、重启读取及失败恢复；检查 `legacy` 和唯一约束 | 08 |
| 防滥用与代理 | 并发登录、分别变化账户和可信来源、伪造转发头；核对限流、响应、日志和 Cookie | 07 |
| 扩展所有权矩阵 | 账户切换后访问草稿、历史、PDF 与执行器绑定 → 不展示上一账户内容，不接续旧任务 | 18 |

补充：模拟 GitHub ID 不变但 login 变化、同邮箱冲突、双身份绑定、授权撤销、无邮箱；真实 GitHub OAuth 和公开仓库分页/限流须在后续实施时独立验证，不用模拟冒充（AC-GH-01～03）。
