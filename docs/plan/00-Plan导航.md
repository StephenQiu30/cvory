## 2. 执行约定

1. 读来源 PRD、其唯一 design，以及 [PROJECT](../../PROJECT.md)、[AGENTS](../../AGENTS.md)、[BACKLOG](../../BACKLOG.md)、[HANDOVER](../../HANDOVER.md)。编码规则以 PROJECT 中已经写下的条款为准。
2. 技术字段或合同缺口先回来源 design 定稿，再同步 PRD 和 Plan。原始需求正文、编号和业务 ID 不改。
3. 实际运行适用检查。条件跳过、Mock 和真实运行分开报告。工具不存在就如实说明。
4. 结果未知时先核对，写操作不盲目重试。失败保留真实状态。
5. 提交、推送和部署遵守最新授权。
