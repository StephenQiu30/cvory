# AI 简历分析与岗位匹配

唯一来源 PRD：[PRD 12](../prd/12-AI简历分析与岗位匹配.md)。PLAN-CV-12。实现范围按设计 02 与已确认选择执行；调度和验收状态见 BACKLOG。

## 1. 交付目标

对固定简历/岗位产生可审阅、有依据的 AI 建议，采纳后只更新私有草稿。

## 2. 执行步骤

1. 固定火山引擎、DeepSeek、OpenAI 官方预设及各自协议；模型由用户自填，不配置第三方转发地址。
2. 在本人私有设置保存、替换和删除 API Key 与模型；使用部署者提供的稳定 `AI_ENCRYPTION_KEY` 加密密钥、分析输入和报告正文，校验缺少/更换密钥后的恢复提示与备份说明。
3. 在 NestJS 落实 owner 隔离的配置、连接测试、预览、分析、报告读取和分页；固定已保存 CV 版本及字段输入，记录提示版本、状态和可获得用量。分析正文和索引元数据均在 7 天后清理。
4. 提供诊断、岗位匹配、选中段落改进和招呼草稿；采纳仅写本地私有草稿，并检查来源 etag、目标原文和本地未保存修改。不能触发发布或投递。
5. 调用前显示模型、实际发送内容、7 天留存和供应商可能收费。用户自行填写自己的 Key；CVory 不设请求数、输入/输出 token 或金额上限。超时、取消、断流、服务商 5xx/不完整响应记为未知或失败并保存可得用量，不自动重放；过期记录自动清理。
6. 使用模拟 provider 与合成 CV 验证缺失事实、异常结构、注入、超时/配额、取消/重复请求、跨账户及部分采纳；对照原文、其他字段、公开页和固定任务材料。真实服务验收须由用户明确选择服务与调用范围，承担供应商费用，模拟不替代真实结果。

## 3. 完成条件

AC-AI-01～07 逐项有证据；未配置对应供应商或未运行真实服务不声明真实模型验收通过。
