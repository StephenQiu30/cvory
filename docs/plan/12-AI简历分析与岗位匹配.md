# AI 简历分析与岗位匹配

唯一来源 PRD：[PRD 12](../prd/12-AI简历分析与岗位匹配.md)。PLAN-CV-12。本文供后续实施使用；当前仅需求与设计评审，不配置密钥或发起真实调用，任务状态见 BACKLOG。

## 1. 交付目标

对固定简历/岗位产生可审阅、有依据的 AI 建议，采纳后只更新私有草稿。

## 2. 执行步骤

1. 在设计内落实火山引擎、DeepSeek、OpenAI 官方三家预设及各自适配，再选具体 model、数据处理与保留、输入/输出预算、每账户限额及真实调用范围；未配置保持基础功能可用，不引入通用 Agent 平台。
2. 为自部署者提供私有预设配置，落实密钥加密、部署主密钥/备份、脱敏回显、替换/删除、空值和失败保全及所有权。连接测试须由用户明确触发，区分真实用量。
3. 在 NestJS 定义 provider 适配、固定输入/请求幂等、结构化结果校验、超时/取消和用量记录；密钥仅服务端，字段按最少必要选择。
4. 建立诊断/岗位匹配/段落改进/招呼草稿入口，展示原文依据、缺失/未知与差异；采纳同时校验 etag、本地修订号/目标原文，服务端或未保存草稿变化均重新核对，不能触发发布或投递。
5. 使用模拟 provider 验证缺失事实、异常结构、注入、超时/配额、取消/重复请求、跨账户、分析中继续输入未保存及部分采纳；对照原文、其余字段、公开页和固定任务材料。
6. 后续在明确选定的服务、预算和数据范围内验证真实质量与用量，记录模型/模板版本；模拟不能替代真实结果，失败时仍可人工处理。

## 3. 完成条件

AC-AI-01～07 逐项有证据；未配置对应供应商或未运行真实服务不声明真实模型验收通过。
