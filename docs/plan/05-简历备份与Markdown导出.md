# 简历备份与Markdown导出

唯一来源 PRD：[PRD 05](../prd/05-简历备份与Markdown导出.md)。PLAN-CV-05。

## 1. 交付目标

提供可恢复的完整备份和保留支持语义的 Markdown。

## 2. 执行步骤

1. 由 NestJS 复用 CV 内容格式及导入协议中的格式版本和资源规则，组装完整内容、有效样式及头像备份，不包含认证信息或自动发布状态。
2. 从后端取得已保存内容，在前端用同一 Tiptap/Markdown 适配器序列化；明确不保留精确模板/分页，与受支持导入语法一致。
3. 接通文件下载和失败重试，保留编辑位置，不新增 CV 或导出记录中心。
4. 在原站资源不可访问的环境恢复 JSON；再次导入 Markdown 比较正文语义，验证异常和重试。

5. 明确下载所选已保存版本；断开原站资源访问再恢复和编辑，核对头像、结构化字段和显隐。注入 PDF／模型不可用故障，确认 JSON／Markdown 不受阻，备份不携带历史集合或执行授权。

## 3. 验证与完成条件

AC-CV-25～28、55、56；TC-CV-13、14、31。实际文件和恢复后的对象分别留证据，不能把私有资源 URL 当成完整备份。
