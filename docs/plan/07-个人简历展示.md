# 个人简历展示

唯一来源 PRD：[PRD 07](../prd/07-个人简历展示.md)。PLAN-CV-07。

## 1. 交付目标

将选定 CV 的公开内容展示在固定网址，并能安全更新或撤回。

## 2. 执行步骤

1. 在管理预览中选择来源与公开字段，显示发布结果及未发布修改；不重新填写人物资料。
2. 由 NestJS 生成筛选后的当前公开结果，在 MySQL 事务内整体替换；普通保存不发布，失败保留旧结果。
3. Next.js 只读取 NestJS 的公开结果，建立响应式只读网页和未发布空状态；公开标题不使用私有版本名，不向浏览器发送完整私有 CV。
4. 实现切换来源、撤回及资源/缓存处理；访客 PDF 未明确选用时不新增入口。
5. 匿名检查网页、初始数据、接口及资源；验证手机、键盘、发布失败和撤回，并在获授权后通过真实目标地址核对公开可达性。
6. 按来源 PRD 验证 GitHub-only 无公开邮箱可按身份发布、存量未绑定邮箱账户仍执行原门槛、存量快照保持、注销等待期不可访问及取消后的旧快照恢复；不能只隐藏前端入口。

7. 对发布／撤回使用版本条件；在两个标签和延迟请求下验证旧候选不覆盖新结果、不复活撤回快照。直接请求删除当前来源验证服务端限制，再核对历史恢复和投递不隐式发布。

8. 建立站主 owner 的显式配置、个人首页及独立工作区路由；首页/稳定个人页读取同一公开快照，以页内目录、自然重排和精选项目便于查阅。
9. 仓库来源与人工贡献形成可预览项目候选，明确发布才进入首页；测试同步失败/改名/转私有后的提示、手工文案保全与撤回缓存。

## 3. 验证与完成条件

AC-CV-33～41、60、61；TC-CV-17～21、34，以及 AC-HOME-01、02。使用合成私有字段哨兵值验证；本机预览不等于网站公开，真实发布尚未执行。
