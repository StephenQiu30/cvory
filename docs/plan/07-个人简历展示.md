# 个人简历展示

唯一来源 PRD：[PRD 07](../prd/07-个人简历展示.md)。PLAN-CV-07。

## 1. 交付目标

将选定 CV 的公开内容展示在固定网址，并能安全更新或撤回。

## 2. 执行步骤

1. 在管理预览中选择来源与公开字段，显示发布结果及未发布修改；不重新填写人物资料。
2. 由 FastAPI 生成筛选后的当前公开结果，在 MySQL 事务内整体替换；普通保存不发布，失败保留旧结果。
3. Next.js 只读取 FastAPI 的公开结果，建立响应式只读网页和未发布空状态；公开标题不使用私有版本名，不向浏览器发送完整私有 CV。
4. 实现切换来源、撤回及资源/缓存处理；访客 PDF 未明确选用时不新增入口。
5. 匿名检查网页、初始数据、接口及资源；验证手机、键盘、发布失败和撤回，并在获授权后通过真实目标地址核对公开可达性。

## 3. 验证与完成条件

AC-CV-33～40；TC-CV-17～20。使用合成私有字段哨兵值验证；本机预览不等于网站公开，真实发布尚未执行。
