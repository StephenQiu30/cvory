# 模板与样式管理

唯一来源 PRD：[PRD 03](../prd/03-模板与样式管理.md)。PLAN-CV-03。

## 1. 交付目标

在少量模板间换版，并独立保存和管理个人样式预设。

## 2. 执行步骤

1. 建立选定内置模板与受支持参数，从默认模板开始；调节字体、字号、行距、间距等范围，不开放任意 CSS 或拖拽画布。
2. 在当前 CV 上提供试用、应用、取消和恢复默认；模板改变排版而不改变内容。
3. 实现个人样式的命名、改名、应用和删除；应用时保存有效参数，后续预设变化不追改 CV。
4. 用长中文、列表、长链接遍历所有选定模板，检查取消还原、默认重置和预设隔离。

## 3. 验证与完成条件

AC-CV-17～20；TC-CV-09、10。预览和保存配置可先验证；同一配置的 PDF 结果在 PDF 能力中核对。
