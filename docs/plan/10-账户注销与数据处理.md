# 账户注销与数据处理

唯一来源 PRD：[PRD 10](../prd/10-账户注销与数据处理.md)。PLAN-CV-10，实施状态见 BACKLOG。

## 1. 交付目标

按照已确认的数据处理规则，安全完成用户主动注销并能核对处理结果。

## 2. 执行步骤

1. 按自助注销、当前密码确认和 7 天等待期实施；备份保留期、无法登录支持和合规保留按部署情况确定。
2. 实现事务冻结、等待期密码取消及清理领取互斥；按设计保留快照供取消恢复、清理在途 PDF，使用可重试任务及备份删除墓碑。只在隔离数据库和合成文件上验证。
3. 实现用户可理解的影响说明和明确确认，并将授权、公开访问、会话撤销、文件与缓存清理纳入已确认流程。
4. 演练重复调用、失败重试、等待期撤销和同时到期、公开撤回及恢复、备份清理与墓碑重放；审计与日志不泄露隐私，按项目检查前后端和浏览器。

5. 用合成历史、恢复草稿、PDF 上下文和待执行投递任务验证冻结与清理；设备撤销后拒绝新领取，备份恢复重放不能恢复已注销账户任务。

## 3. 完成条件

AC-USER-14～17、19 和来源 PRD 的验证场景通过；真实用户数据不用于演练。依赖与阻塞见 BACKLOG。
