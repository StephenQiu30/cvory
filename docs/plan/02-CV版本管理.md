# CV版本管理

唯一来源 PRD：[PRD 02](../prd/02-CV版本管理.md)。PLAN-CV-02。

## 1. 交付目标

让已有 CV 成为可命名、独立修改和删除的用途版本。

## 2. 执行步骤

Nest 首切片通过 `cv_revisions` 与 CV 更新事务保存历史，使用可配置数量上限；覆盖首次存量修改、空保存、并发重试和恢复为独立 CV。前端编辑器提供历史入口；完整正文预览、旧文件资源与公开/注销联动继续按下列步骤验证。

1. 在我的 CV 列表实现名称、最后保存时间、模板及公开来源标识，操作始终针对稳定 ID。
2. 实现改名与复制，拷贝完整内容、显示状态和有效样式；防止重复确认建多份，原件/副本后续互不追改。
3. 实现删除与取消；删除公开来源前要求切换或撤回，不连带静默清空展示。
4. 分别修改原件和副本，再重开核对；验证同名、重复确认、取消与公开关联的删除约束。

5. 按设计为成功变更保存形成不可变历史，加入列表、预览及幂等恢复新副本；配置并展示真实保留范围，关联 CV／账户清理，不实现分支合并。
6. 用真实 API 验证快照不变、照片及样式恢复、跨账户拒绝和删除约束；将复制、恢复与公开／投递联动检查纳入同一组合成数据。

## 3. 验证与完成条件

AC-CV-03、04、13～16、47～49；TC-CV-02、07、08、26、27。公开关联的数据约束可先用合成关联验证，公开能力完成后补真实跨流程验证。
