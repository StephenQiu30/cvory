# 邮箱验证与账户恢复

唯一来源 PRD：[PRD 09](../prd/09-邮箱验证与账户恢复.md)。PLAN-CV-09，建议方案，待确认后实施。

## 1. 交付目标

使用户能验证邮箱并安全恢复或更新凭据；实际投递必须可验证。

## 2. 执行步骤

1. 评审设计中验证前私有访问与发布门槛、24 小时验证／30 分钟重置、发送配额及 15–128 位新密码建议；确认发信渠道、域名、泄露密码数据来源和人工支持路径后回写设计和 PRD。
2. 为账户验证状态与一次性令牌制定版本化迁移及原子消费事务，覆盖旧账户、重复操作、邮箱快照、跨账户确认、邮件扫描、过期、并发和回滚；令牌只存哈希，发送密文短期保留。
3. 建立经确认的邮件发送边界、重试与清理，确保发送失败不伪装成功，不在日志泄露凭据；控制邮箱枚举与限流。
4. 实现验证、重置、凭据修改和会话撤销的 API、OpenAPI 客户端和当前页面流程；旧账户仍可登录并保留历史公开快照，发布验证门槛在服务端执行，错误和超时保留安全上下文。
5. 在隔离数据库和受控收件箱分别验证各状态、并发与重放、旧会话撤销、枚举防护以及实际投递；运行项目适用的后端、前端与浏览器检查。

## 3. 完成条件

AC-USER-09～13 和 PRD 对应场景通过；只有模拟邮件时不得声称真实投递验证。依赖与阻塞见 BACKLOG。
