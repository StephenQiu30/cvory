# PDF导出

唯一来源 PRD：[PRD 06](../prd/06-PDF导出.md)。PLAN-CV-06。

## 1. 交付目标

从固定的已保存内容生成可投递 PDF。

## 2. 执行步骤

1. 保存成功后固定本次内容、有效样式和资源；生成中继续编辑不改变本次输入。
2. 共用正文/模板建立 A4 打印样式，处理长段落、列表、链接和分页，不使用截图作为正文。
3. 接入 Chromium 并等待字体/头像，使用所有者私有下载入口，输出清楚文件名和可重试错误。
4. 在目标运行环境生成每种模板的单/多页真实 PDF，离线打开、搜索复制、点击链接，检查裁切、字体、水印和空页。

## 3. 验证与完成条件

AC-CV-29～32；TC-CV-15、16。生成失败与文件内容质量分别检查，浏览器下载事件不代表文件验收通过。
