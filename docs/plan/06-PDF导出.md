# PDF导出

唯一来源 PRD：[PRD 06](../prd/06-PDF导出.md)。PLAN-CV-06。

## 1. 交付目标

从固定的已保存内容生成可投递 PDF。

## 2. 执行步骤

1. 由 FastAPI 在保存成功后固定本次内容、有效样式和资源；生成中继续编辑不改变本次输入。
2. 在 Next.js 共用正文/模板建立受保护的 A4 打印视图，读取固定导出上下文；处理长段落、列表、链接和分页，不使用截图作为正文。
3. 由 FastAPI 接入 Python Playwright 与匹配的 Chromium，仅访问固定的内部打印视图，等待字体/头像后私有下载；限制并发、超时并清理临时上下文，输出清楚文件名和可重试错误。
4. 在目标运行环境生成每种模板的单/多页真实 PDF，离线打开、搜索复制、点击链接，检查裁切、字体、水印和空页。

5. 精确预览使用同一固定输入生成的 PDF；编辑预览保留近似分页说明。故障注入字体／图片失败、繁忙、超时和取消，检查后台最终清理及保存／备份降级可用。
6. 在声明的单进程部署验证票据、重启及隔离；若扩展多 worker／实例，先落实设计中的共享上下文或可靠路由，再验证跨进程生成、过期及清理；未通过不启用该拓扑。

## 3. 验证与完成条件

AC-CV-29～32、57～59；TC-CV-15、16、32、33。生成失败与文件内容质量分别检查，浏览器下载事件不代表文件验收通过。
