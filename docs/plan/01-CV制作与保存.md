# CV制作与保存

唯一来源 PRD：[PRD 01](../prd/01-CV制作与保存.md)。PLAN-CV-01。

## 1. 交付目标

形成可新建、编辑、保存并重开的 CV，是其他能力使用的内容基础。

## 2. 执行步骤

1. 按 PROJECT 的目录与规范，在 frontend/ 建立 Next.js 前端、backend/ 建立 FastAPI 后端，锁定精确依赖、Python 版本与包管理器；明确所有者登录及运行配置，接入 MySQL、迁移与私有头像目录。把真实运行与检查命令登记 PROJECT 和 README。
2. 在管理页面及 CV 模块实现新建、基本资料、重复经历、排序/隐藏与头像；使用稳定对象标识，不把示例写成真实内容。
3. 接入受限 Tiptap 和 Markdown 输入，正文 JSON 统一保存与只读渲染；中文组合输入、格式取消和键盘操作可用。
4. 在 FastAPI 实现校验、事务和条件更新，按 PROJECT 的 API 约定生成 OpenAPI 与前端类型。前端接入保存反馈、失败保留与重试、etag 冲突提示，新修改不能被旧响应确认或覆盖。
5. 真实保存后关闭并重开服务，核对 MySQL 与头像持久化读回；验证断网、双标签、不支持粘贴、未登录写入、校验错误形状和旧 etag 拒绝。
6. 将管理工作区组织为独立路由组，建立共享 BasicLayout、Header、Footer；按参考页建立左侧简历条目、右侧模板／Markdown／导入标签的双栏工作台和窄屏纵排；复用真实公开管理、改名、复制、导出和导入流程，使用 shadcn 风格组件及 Radix Dialog/Tabs，编辑路由继续使用沉浸式布局。

## 3. 验证与完成条件

AC-CV-01、02、05～16；TC-CV-01、03～06。保留持久化读回和真实浏览器证据，不以组件快照代替保存成功。
