# CV制作与保存

唯一来源 PRD：[PRD 01](../prd/01-CV制作与保存.md)。PLAN-CV-01。

## 1. 交付目标

形成可新建、编辑、保存并重开的 CV，是其他能力使用的内容基础。

## 2. 执行步骤

1. 按设计中的运行方案建立最小 Next.js 工程和必要的身份/持久化；将真实运行与检查命令登记 PROJECT 和 README，不先建一套无用户结果的基础平台。
2. 在管理页面及 CV 模块实现新建、基本资料、重复经历、排序/隐藏与头像；使用稳定对象标识，不把示例写成真实内容。
3. 接入受限 Tiptap 和 Markdown 输入，正文 JSON 统一保存与只读渲染；中文组合输入、格式取消和键盘操作可用。
4. 实现保存反馈、失败保留与重试、旧版本冲突提示；新修改不能被旧响应确认或覆盖。
5. 真实保存后关闭服务再打开，核对字段、正文、顺序、隐藏状态与头像；验证断网、双标签及不支持粘贴。

## 3. 验证与完成条件

AC-CV-01、02、05～12；TC-CV-01、03～06。保留持久化读回和真实浏览器证据，不以组件快照代替保存成功。
