# 简历导入

唯一来源 PRD：[PRD 04](../prd/04-简历导入.md)。PLAN-CV-04。

## 1. 交付目标

把支持的已有文件变成经过校对的新 CV，不覆盖原件。

## 2. 执行步骤

1. 在设计中明确支持格式、限额与资源处理；文件选择前显示限制，同时做服务端校验。
2. 核心 JSON／Markdown 在浏览器按共用适配器读取，服务端校验结构及资源；必需的 DOCX/有文字层 PDF 在受限私有任务中提取内容；保留候选字段、未归类原文和警告。损坏、扫描或未知版本不能返回空白成功，不维护第二套富文本转换器。
3. 实现校对与归类，确认才另存私有 CV；取消、失败及重复确认不影响原件，也不自动公开。
4. 用每种选定格式的真实合成文件验证正常、限额边界、损坏与无文字输入，再核对创建后的 CV。

5. 采用条目／字段定点校对，保留稳定 ID 及未编辑字段；导入真实 JSON 文件、只改一段正文、保存重开并再次备份，比较完整结构。
6. MD/DOCX/文字 PDF 脱离模型与竞品后台逐格式验证；扩展猫步/JSON Resume 按版本另建映射，未完成不开放为支持，不以安装解析库代替验收。

7. DOCX 段落/表格与 PDF 页码/文本转为统一校对候选；验证多栏、扫描无文字层、加密和损坏。扫描件提示暂不支持，不接 OCR；预算包括展开体积、页数、时间/内存，取消/到期清理原件，确认幂等另存。

## 3. 验证与完成条件

AC-CV-21～24、52～54；TC-CV-11、12、29、30，以及 AC-IMPORT-01、02。文件能上传或提取文字不等于完成 CV 导入，必须核对校对后结果。
