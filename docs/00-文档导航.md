# 文档中心

[业务需求 04](requirement/04-个人CV制作与管理需求说明.md)对应一份[产品设计 02](design/02-CV制作管理与展示设计.md)，再按可独立交付的用户结果拆[PRD](prd/00-PRD导航.md)和[Plan](plan/00-Plan导航.md)。规范、过程状态和技术约束不写成业务需求。

| 入口 | 内容 |
| --- | --- |
| [业务需求](requirement/00-需求导航.md) | 最初诉求原文和精简业务说明 |
| [设计](design/00-设计导航.md) | 共用方案、必要取舍 |
| [PRD](prd/00-PRD导航.md) | 每项能力的用户结果与验收 |
| [Plan](plan/00-Plan导航.md) | 对应能力的执行步骤与验证 |
| [调研结论](research/00-调研导航.md) | 竞品结论、来源和局限 |
| [写作模板](templates/00-模板导航.md) | 必要正文结构，不要求机械填满 |
| [Obsidian](01-Obsidian使用说明.md) | 阅读与维护 |
| [PROJECT](../PROJECT.md)、[AGENTS](../AGENTS.md) | 工程与文档规则、协作流程 |
| [DESIGN](../DESIGN.md) | 品牌、字体、配色及通用交互 |
| [BACKLOG](../BACKLOG.md) | 唯一任务调度入口 |
| [HANDOVER](../HANDOVER.md) | 最近一次交付证据 |

一个需求对应一个产品设计；设计可对应多个 PRD，PRD 可对应多个 Plan。每个下游文档只有一份直接来源，不复制背景、技术规则或状态。临时稿、过程确认、提示词与重复摘要不保留在项目中。
